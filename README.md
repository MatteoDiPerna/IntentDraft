# IntentDraft

You explain what you want. We help you turn that into clear instructions for your LLM.

Monorepo: `frontend/` (Vite + React) and `backend/` (Fastify + Prisma).

## Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173` (HashRouter).
