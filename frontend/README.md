# PromptPilot — Frontend

UI conversazionale basata su [react-typescript-template](https://github.com/luismalamoc/react-typescript-template) (Vite, React, TypeScript, Tailwind, Radix Slot).

## Avvio locale

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Apri `http://localhost:5173`. In fase 1 l'auth e le conversazioni usano **mock** (`VITE_USE_MOCK=true`).

## Script

| Comando | Descrizione |
| ------- | ----------- |
| `npm run dev` | Dev server |
| `npm run build` | Build produzione |
| `npm run preview` | Anteprima build |
